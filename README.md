# Quadruped Robot — 四足机器人

12 自由度四足机器人：4 腿 × 3 自由度（髋横摆 / 髋俯仰 / 膝），trot 对角步态。

## 硬件分层

| 层 | 板子 | 职责 | 频率 |
|---|---|---|---|
| 上层：步态规划 | 树莓派 5 | CPG 步态发生器、足端轨迹、串口封包 | 10 Hz 规划 / 50 Hz 下发 |
| 下层：关节控制 | ESP32 | IMU 融合、FSR 读数、解析逆解、12 路 PWM、超时缓停 | 100 Hz |

ESP32 的 LEDC 有 16 路 PWM，12 个舵机刚好够用。

## 步态

trot 对角步态：CPG 四振荡器耦合，对角腿同相（左前 + 右后 / 右前 + 左后），相位差 180°。
足底 FSR 接触信号触发 CPG 相位复位，支撑相 / 摆动相切换靠它。

## 通信协议（UART 115200）

帧格式：`0xAA 0x55 | 长度 | 命令 | 数据 | CRC16-CCITT | 帧尾`
- 关节角 50 Hz 下发，丢帧不重传（下一帧 10 ms 就到）
- 重要命令带序列号 + ACK
- 超时 100 ms 没收到帧 → ESP32 原地缓停

## 模块

```
pi/
  cpg.py             # CPG 四振荡器 trot 步态，输出 12 路关节角
  uart_link.py       # 封包 / CRC16 / 序列号 + ACK / 看门狗
esp32/
  joint_controller.cpp  # 100 Hz：IMU + FSR、解析逆解、12 路 PWM、超时缓停
  uart_parser.cpp       # 解包、CRC 校验、坏帧丢弃
```
